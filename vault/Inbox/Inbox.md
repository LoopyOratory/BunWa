# 📥 Inbox

Scratch space for notes that aren't ready to live in a section yet.

Promotion rules:

1. Decide which section it belongs to (`01 Architecture` … `10 Reference`).
2. Give it proper frontmatter (`type`, `tags`, `updated`, and `status` if it is a feature).
3. Link it from [[Home]] and from at least one neighbouring note — an orphan note is a lost note.
4. Move the file into that folder.
